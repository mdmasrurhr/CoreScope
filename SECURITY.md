# Security

## Reporting a problem

Please report security problems privately through GitHub: **Security → Report a vulnerability** on this repository.
Do not open a public issue for them.

## What CoreScope does on your PC

- It runs as a normal app. Administrator rights are requested only when you click **Unlock full sensors** or approve a fix that needs them.
- Every fix that changes something asks first and says what it will do.
- It installs no drivers and has no account or telemetry. The only network use is the optional update check and the speed test.

## Supported versions

Only the latest release gets fixes.
